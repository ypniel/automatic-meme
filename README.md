# Our Home 🏡

A simple app for David & Yesy to manage furniture shopping and shared budgeting.

## Features

- **Shopping List** — add furniture items with thumbnail, store link, price, and qty. Mark items as purchased and track total spend.
- **Budget Tracker** — log income and expenses split by David, Yesy, or 50/50. See each person's monthly net savings and a combined summary.

## Deploy

Hosted on Vercel, connected to this GitHub repo. Any push to `main` triggers an automatic redeploy.

## Usage

Open the app and use the two tabs:

1. **Shopping** — add items, paste a product URL and image link, set qty and price.
2. **Budget** — add income or expenses, choose who it belongs to, pick a frequency (weekly / fortnightly / monthly / annual). The app converts everything to monthly for comparison.

Data is saved in the browser (localStorage) — no account needed.
